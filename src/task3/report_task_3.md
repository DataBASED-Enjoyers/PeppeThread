# Задание 3: Задача Дирихле

## Описание задания  
Реализовано параллельное решение задачи Дирихле методом Гаусса-Зейделя с использованием волновой схемы. Пластина разбивается на блоки, и процессы обмениваются граничными данными.

## Численные эксперименты  
Рассматриваемые размеры области:  
- $100 \times 100$, $500 \times 500$, $1000 \times 1000$.  
Количество процессов: 4, 16, 64.  

## Результаты замеров времени  

| Размер области $N \times N$ | Кол-во процессов $P$ | Время выполнения (с) | Ускорение $S$ | Эффективность $E$ |
|------------------------------|------------------------|-----------------------|-----------------|--------------------|
| $100 \times 100$           | 4                      | X.XXX                 | X.XXX           | X.XXX              |
| $500 \times 500$           | 16                     | X.XXX                 | X.XXX           | X.XXX              |
| $1000 \times 1000$         | 64                     | X.XXX                 | X.XXX           | X.XXX              |

## Графики  

### Время выполнения  
- **Оси:**  
  - $y$: Время выполнения (секунды).  
  - $x$: Количество процессов $P$.  

### Ускорение $S$  
- **Оси:**  
  - $y$: Ускорение.  
  - $x$: Количество процессов $P$.  

### Эффективность $E$  
- **Оси:**  
  - $y$: Эффективность.  
  - $x$: Количество процессов $P$.  

## Выводы по заданию 3  
- Волновая схема показала высокую производительность на больших областях.  
- Для малых областей эффективность падает из-за избыточного обмена данными.

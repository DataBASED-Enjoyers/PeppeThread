# Задание 2: Решение уравнения в частных производных

## Описание задания  

Реализован алгоритм решения уравнения Пуассона методом Гаусса-Зейделя с использованием OpenMP. Вычисления проводятся на прямоугольной сетке с разным числом точек и потоков.

![](benchmarks/temperature_distribution.png)

## Численные эксперименты

Рассматриваемые размеры сетки:

- $50 \times 50$
- $100 \times 100$
- $200 \times 200$
- $300 \times 300$.  

Количество потоков: от 1 до 10.

## Основные метрики параллельной реализации

Для оценки эффективности параллельной реализации используются следующие метрики:

- **Ускорение (S)**:

  $`
  S = \frac{T_{\text{послед}}}{T_{\text{паралл}}}
  `$

- **Эффективность (E)**:

  $`
  E = \frac{S}{nthreads}
  `$

## Выводы по заданию 2  

1. **Ускорение (S):**  
   - Ускорение растёт с увеличением числа потоков, но для больших размеров сетки рост более выражен.  
   - Для малых размеров сетки ($50 \times 50$) прирост ускорения замедляется из-за накладных затрат на синхронизацию потоков.

2. **Эффективность (E):**  
   - Эффективность выше для больших сеток ($200 \times 200$ и $300 \times 300$), так как вычисления доминируют над накладными затратами.  
   - Для малых размеров сетки эффективность снижается с увеличением числа потоков.

3. **Общая тенденция:**  
   - Метод Гаусса-Зейделя эффективно масштабируется для больших размеров сеток, особенно при умеренном числе потоков.  
   - Для небольших размеров сеток число потоков следует ограничивать для минимизации накладных затрат.
